# v1.2.0 — visual Apply and independent lighting prototype

This is the tested NeoForge 1.21.1 reference for the visual designer. The finished feature set is now ported to all other nine targets. Keep the full source tree; target E builds this reference. See the root PORTING-1.2.0.md and TESTING-ALL-VERSIONS.md for the complete matrix.

- The old actual block-light level was 13; the maximum remains 15 (13 + 2). Glow now has four buttons: 0 = light level 0, 1 = level 8, 2 = level 12, and 3 = level 15. It works independently of the Emission ON/OFF toggle. Emission affects only the symbol's emissive texture; Glow emits actual block light.
- Enabling Emission costs one glow ink sac. Changing Glow to option 1/2/3 costs 1/2/3 glowstone dust respectively; switching it off is free. An unchanged Glow setting costs nothing, including when another visual property changes. Materials are still consumed only on Apply. Existing saved slider values remain unchanged until edited; pasting an old intermediate value selects the next available preset. The server rejects changes to non-preset light levels, and the designer network revision requires matching updated clients and server. Older plates without a saved light value retain emission and default to light level zero.
- All three tabs stage visual changes until Apply, including free symbol choices. Apply is disabled for an unchanged draft or missing materials. One complete appearance packet is validated and committed on the server; duplicate or stale requests cannot charge twice. The stonecutter result sound plays after success.
- Backgrounds are on the left and frames on the right. Each changed background costs one corresponding log/stem/block; Iron and None backgrounds are free. A changed Iron/Copper/Gold/Coal frame costs one matching ingot/coal; None is free. Removing tint or emission is free. Costs combine in the common footer with item icons, required quantities and available-count tooltips.
- The supplied Coal PNG is used unchanged and appended to the existing frame IDs. There is still one registered plate block and item.
- Copy saves the full selected appearance, including unapplied changes, in a client-session clipboard. Paste stages it without spending or applying anything. The clipboard survives switching plates until the client exits. Paste is disabled with an explanatory tooltip before the first copy.
- Closing any dirty tab prompts about unapplied visual changes. Return to editing retains the draft and the current tab. Empty search results are wrapped and centered separately in the Background and Frame grids, with light-gray text; Symbols uses the same light-gray text.
- Grid entries use the same fixed 24-pixel pitch horizontally and vertically (22-pixel entries with 2-pixel gaps). The main panel fits an odd number of whole columns so Background and Frame split into identical widths, each with the same column count. All grids leave only two pixels before their scrollbar. The Symbols grid, its border and scrollbar are shifted three pixels right so its left border aligns with the search/category controls; its right border extends three pixels beyond them. Other tabs keep their previous horizontal positions. The default panel is slightly narrower to fit this layout. Grid content still stops one pixel above the bottom frame border. Scrolling entries now clip at the inside top edge of the frame, two pixels above their unscrolled origin, so the top border does not leave a hidden strip. Cell visibility, hover and click checks use that same top edge. Background/Frame headings move from y=76 to y=60, and both grids move up 24 pixels and gain 24 pixels of height (one full row), with their bottom edges and footer positions preserved. Empty-search messages follow the new grid positions.
- Emission and the four Glow buttons have no hover tooltip. Dye cells show the dye item's native tooltip, including any item tooltip additions from installed mods, instead of the custom inventory/cost text. No Colour retains its existing tooltip; Apply, resource requirements and the other tabs retain their tooltips.
- Pick-block, item components, placement and saved block entities preserve the new light level. Sponge clears tint, symbol emission and block light while retaining the symbol/frame/background.

Validation for this polish: Java syntax validation passed for all 30 NeoForge 1.21.1 source files. 11,460 geometry assertions passed across supported GUI widths, using the production geometry methods unchanged in a standalone fixture; checks cover equal horizontal/vertical pitch, two-pixel scrollbar clearance, equal pane widths, Symbols left alignment, top and bottom clipping, one extra Background/Frame row, fixed footer positions and Glow button fit. The updated reflection-based GeometryChecks.java remains available for running against compiled Minecraft classes. The preceding revision passed direct Minecraft/NeoForge API compilation and 20,936 appearance, material-cost, migration and packet checks; this polish leaves those costs and packets unchanged. Every file outside the NeoForge 1.21.1 target is byte-identical to the previous full source.

Full API/Gradle compilation and in-game rendering of this polish revision are not verified here.
